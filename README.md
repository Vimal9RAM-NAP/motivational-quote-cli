# 💬 Motivational Quote CLI

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
A lightweight Node.js command-line tool that displays randomized, beautifully formatted motivational quotes directly in your terminal.

## 🚀 Features

- **Random Quotes:** Fetches a new inspiring quote every time it runs.
- **Terminal Styling:** Styled using `chalk` for clear, readable, colored output.
- **Lightweight:** Built with minimal dependencies to ensure fast startup.

## 🛠️ Installation & Usage

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### 1. Clone the repository:

```bash
git clone [https://github.com/Vimal9RAM-NAP/motivational-quote-cli.git](https://github.com/Vimal9RAM-NAP/motivational-quote-cli.git)
```

```bash
cd motivational-quote-cli
```

### 2. Install dependencies:

```bash
npm install
```

### 3. Run the script:

```bash
node index.js
```

## 🧰 Tech Stack & Dependencies

- **Runtime**: Node.js
  - **Packages**:

  - **inspirational-quotes** — For retrieving quotes.

  - **chalk@4.1.2** — For ANSI terminal text styling.
